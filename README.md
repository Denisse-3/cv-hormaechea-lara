# Currículum Vitae-TP1
Este trabajo se realizó para la materia Computación III, con el fin de crear un archivo .html dónde se desarrolló un currículum vitae que podrá verse en la web.
## Secciones utilizadas
- **Header**: Esta sección se utilizó para el espacio de navegación.
- **Main**: Se utilizó para separar el contenido (*yo*, *perfil*, *formación y experiencia*, *software* y *proyectos*). 
- **footer**: Utilizado para el logo y derechos.
### Información 
- **Editor de código**: Visual Studio Code
